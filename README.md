Personal portfolio site built with React, TypeScript, and Sass. Showcases my background as a Software Engineer, including:

- **Expertise** — Mobile app development (Flutter/Dart), backend & database engineering (Django, PostgreSQL, Supabase), and AI/embedded systems (TensorRT, Jetson Nano, Computer Vision)
- **Projects** — FreshMart, StayEase, OphthoCARE, and a C++ search engine
- **Career history** — Software Engineering internship at RiseTech, COMPPEC 2026 award, and NUST education
- **Contact form**

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Build & Deploy

```bash
npm run build
npm run deploy
```

Deploys to GitHub Pages via `gh-pages`.
